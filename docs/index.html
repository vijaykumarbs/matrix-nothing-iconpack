Stock Nothing Launcher note

Nothing Launcher does not yet expose a reliable third-party icon-pack picker, and nothing's icon shape and Themed Icons settings take priority. Matrix targets the standard icon-pack protocol, so it works fully in Nova, Lawnchair, Niagara, Hyperion, Kvaesitso, Smart Launcher and friends. Every icon also ships a monochrome layer for themed-icon modes.

Verify a download

shasum -a 256 -c SHA256SUMS.txt

Checksums ship with every release. Release APKs are signed with a 4096-bit RSA key using APK Signature Scheme v2 and v3.

What the pack includes

  • 126 curated icons — Google, Nothing, social, work, media, finance, shopping and travel.
  • 160 component mappings — regional and alternate activities map to the same glyph.
  • Adaptive + monochrome — background, tinted foreground and themed layer on every icon.
  • Theme-friendly UI — dark surface, edge-to-edge insets, display-cutout aware, no forced orientation.
  • Fast by construction — vector-only resources, no bitmaps, no runtime XML parsing, no network calls.

06 — Security

Nothing to take.

An icon pack should be a picture book, not a platform. Matrix asks for no permissions and opens no sockets.

Zero permissions

No INTERNET, storage, location or package-list permission. The manifest declares nothing to grant.

No background work

No services, receivers, providers, alarms or scheduled jobs. The app exists only while it is open.

Signed & reproducible

v2/v3-signed release APKs, published SHA-256 sums, open source and built in public CI.
